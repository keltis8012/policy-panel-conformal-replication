# Replication Package

**Risk-Controlled Conformal Decision Rules for Policy-Change Events in Panels**

This package reproduces every number, table and figure in the manuscript from the
public OECD source series. It is organised as `data/ → code/ → results/`.

---

## 1. Environment

| Item | Value |
|---|---|
| Python | 3.11+ (tested on 3.11 / 3.13) |
| Packages | `numpy`, `pandas`, `scipy`, `matplotlib` (see `requirements.txt`) |
| OS | platform-independent; no compiled extensions required |
| Runtime | full pipeline < 2 minutes on a laptop |

```bash
pip install -r requirements.txt
```

## 2. Data

`data/` holds a frozen snapshot of the three OECD series used in the paper.
Files are gzip-compressed to stay within repository size limits.

| File | Series | Rows | Role |
|---|---|---|---|
| `oecd_eps_1990_2020.csv.gz` | Environmental Policy Stringency index | — | trigger variable `S_it` |
| `oecd_ghg_co2_2000_2023.csv.gz` | Greenhouse-gas air emissions (CO2, CH4, N2O, GHG) | — | outcome `y_it`, placebo outcomes |
| `oecd_green_growth_2000_2020.csv.gz` | Green Growth indicators (real GDP) | — | mechanism correlate (§4.3) |

* **Source**: OECD Data Explorer (SDMX), retrieved 2026-08.
* **Vintage**: the panel's right edge (2020) is set by the EPS vintage; emissions
  extend to 2023 but are truncated to the common window.
* **Licence**: OECD terms of use (public, attribution). The snapshot is redistributed
  here for reproducibility only; the original series remain the authoritative source.
* `code/aux_fetch.py` re-downloads the series from SDMX if a fresh pull is preferred.

Decompress before running:

```bash
gunzip -k data/*.csv.gz
```

## 3. Code

| Script | Reproduces |
|---|---|
| `code/e01b_empirical.py` | Main decision pipeline: triggers, rolling calibration, three arms, releases/verdicts → Tables 4, 5, 8, 9; Figures 2, 3, 6, 7 |
| `code/tau_sensitivity.py` | Trigger-threshold grid P70/P75/P80/P90 → Table 9 (threshold sensitivity) |
| `code/aux_run.py` | Placebo outcomes (CH4, N2O, GHG) → Table 6 |
| `code/aux_fetch.py` | Re-download of OECD series |
| `code/_recompute_aeff.py` | Forward reading of the effective level (α_eff) → Table 4, §4.2 |
| `code/_placebo_forward.py` | Forward α_eff for the placebo outcomes → Table 6 |

Run order:

```bash
python code/e01b_empirical.py        # main pipeline, writes a timestamped run dir
python code/tau_sensitivity.py       # threshold grid
python code/aux_run.py               # placebo outcomes
python code/_recompute_aeff.py       # forward α_eff, prints the Table 4 grid
python code/_placebo_forward.py      # forward α_eff for Table 6
```

## 4. Results

`results/` contains the archived artefacts referenced by the manuscript's
provenance register (Appendix C.1):

| File | Content |
|---|---|
| `results/decision_timing.csv` | Per-event decision record: country, trigger year, arm, margin, verdict |
| `results/post_analysis.json` | Run-level summary: quantiles, boundary events, arm statistics |

Further run archives (per-arm widths, overlap, panel extract) are regenerated by
`e01b_empirical.py` into a timestamped directory under `04_output/experiments/`.

## 5. Conventions that must match to reproduce the tables

These are frozen design choices, not tuning parameters:

| Symbol | Value | Meaning |
|---|---|---|
| `TAU` | 0.222 | trigger threshold, empirical upper quartile of \|ΔS\| |
| `MIN_K` | 5 | minimum calibration length; the window expands with a rolling origin |
| `ALPHA` | 0.10 | nominal level (grid also runs 0.05, 0.20) |
| `COOLDOWN` | 24 months | minimum gap between a country's trigger years |
| α_eff | forward reading | exceedance of `q_t` by the decision-year residual, over 130 valid decisions |
| ε^grp | guarantee version | `min(0.1316 w, 0.0789)`, evaluated at 0.0263 for this panel |
| b_t floor | 0.684 | flat bound `1 − α − 0.19 − ε^grp` |

The panel fixes N = 39 countries and T = 21 years (2000–2020), giving 135 trigger
events, 132 trigger residuals and 130 valid decisions; the three counts are used
for different denominators and are documented in Appendix C.1 of the manuscript.

## 6. Determinism

All random draws use explicit seeds recorded in the run configuration; no result
depends on wall-clock state. Re-running `e01b_empirical.py` on the bundled snapshot
reproduces 135 triggers / 130 decisions / 9 naive releases / 5 false releases exactly.
